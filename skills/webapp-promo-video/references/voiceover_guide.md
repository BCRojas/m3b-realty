# Voiceover Script Guide

## Speaking Rate Reference

| Style | Words per minute | Words per 60s video |
|---|---|---|
| Slow / deliberate | 100–120 | 100–120 |
| Conversational | 130–150 | 130–150 |
| Energetic / fast | 160–180 | 160–180 |

The TTS engine will be speed-fitted to match the video duration, so write naturally — the `mix_audio.sh` script handles synchronization automatically.

## Proven Script Structure (60s video)

```
[0–5s]   Hook — bold, punchy problem/promise statement
[5–15s]  Pain point — one sentence on what the viewer is struggling with
[15–35s] Solution walkthrough — step-by-step, one sentence per step
[35–45s] Social proof / outcome — what happens after they use it
[45–55s] Feature highlight — 2–3 key differentiators
[55–60s] CTA — direct, specific, urgent
```

## Tone Guidance by Voice Type

| Voice | Tone | Avoid |
|---|---|---|
| Energetic male | Fast-paced, punchy, short sentences, exclamation | Jargon, passive voice |
| Professional female | Clear, confident, measured pace | Slang, over-enthusiasm |
| Warm friendly | Conversational, inclusive, empathetic | Hard sell, urgency pressure |

## CTA Formulas That Work

- "Build your website today at [domain]."
- "Start free at [domain] — no credit card required."
- "Try it now at [domain]. It takes less than five minutes."
